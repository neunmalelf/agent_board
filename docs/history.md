# History

The project history lives at [`history.md`](https://github.com/neunmalelf/agent_board)
in the repository root (newest entry on top; the latest entry doubles as the
release notes). This page exists so the MkDocs nav can link to it.

## Rules (summary)

1. One entry per version bump in `history.md`, newest first, written before
   the release commit.
2. Working archives in `history/`: `prompts/`, `changes/`, `todo/`,
   `plans/`, `tests/`, `ideas/`, `goals/` — filenames carry a unified
   `YYYYMMDDThhmmss` timestamp; archived files are never deleted.
3. Decisions get a dated entry including reasoning and rejected
   alternatives (example: the 2026-09-13 textual evaluation).

Full rules: `.agentrules` (History Rule) and `docs/development.md`.
